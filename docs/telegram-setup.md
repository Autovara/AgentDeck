# Telegram Setup

> Status: draft. Final content lands when Telegram pairing is implemented.

This document will describe how to:

- create a Telegram bot with `@BotFather`
- pair the bot with AgentDeck locally
- allowlist your Telegram user ID
- enable read-only commands (`/help`, `/status`, `/agents`, `/attention`, `/session`)
- enable the guarded `/mute` and `/stop` actions
- revoke Telegram access locally

Until Telegram pairing is implemented, this page is intentionally empty.

Security expectations for Telegram control are defined in [`security.md`](security.md).
